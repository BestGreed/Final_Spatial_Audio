Final Spatial Audio — Windows x64 便携版
======================================

一、快速开始

1. 将压缩包完整解压到你有写入权限的固定文件夹，例如 D:\Apps\Final Spatial Audio。
2. 双击 bin 文件夹中的 FinalSpatialAudio.exe。程序常驻通知区域，没有主窗口；图标可能在任务栏“显示隐藏的图标”中。
3. 左键或右键点击托盘图标，打开音频模式菜单。
4. 首次启动处于手动锁定状态，不会主动改变当前声音。选择模式后才会执行切换；勾选“自动切换”才启用策略。

系统要求：Windows 11 x64。使用系统自带组件、字体与 C 运行时，无需另装 WinUI、Windows App SDK、.NET、Python 或音频辅助工具。Atmos / DTS:X 需要设备、连接和 Windows 对应空间音频组件支持，本程序不附带或代替这些组件。

请保留 bin 与配置文件的目录关系，不要单独移动 EXE。不要直接在压缩包内运行，也不要放入不可写的受保护目录。程序会在 bin 的上一级目录保存配置快照及日志。建议使用较短的路径。

二、文件内容

bin\FinalSpatialAudio.exe    主程序，已内嵌图标
final-spatial-audio.ini      规则配置（示例默认禁用）
使用说明.txt                 本说明
LICENSE.txt                 源码许可
THIRD_PARTY_NOTICES.md        许可范围及运行时说明
licenses/                   图标与编译运行时许可声明
SHA256SUMS.txt               文件校验值

这是干净分发包，不含开发工具、源代码、测试程序、本机设备快照、日志或个人自启注册信息。首次使用后生成的 profiles 文件夹及日志属于正常运行数据。

三、手动与自动切换

主菜单支持 Stereo、5.1、7.1、Dolby Atmos、DTS:X。
• 点击任一可用模式：恢复该模式配置，并取消“自动切换”勾选。
• 勾选“自动切换”：按所有规则的最高优先级统一选择模式。
• 取消勾选：进入手动锁定，不再按规则切换。
• 检测到你在 Windows 或其他软件中手动修改音频后：取消自动勾选，保留外部修改。
• 退出程序：保留当前声音设置。

托盘图标表示实际读回的音频模式，不用 FSA 主程序标识代替模式图标。无法识别或设备不可用时显示问号。

四、首次设备配置

首次使用当前默认输出时，程序建立 Stereo、5.1、7.1 的默认配置：24 位有效精度 / 48 kHz，使用 32 位容器；共享混音格式为 float32 / 48 kHz。默认将主扬声器设为全频，LFE 不计入主扬声器大小标记。初始化仅生成配置，不直接写入系统音频。

5.1 优先保留当前可识别布局，并在必要时探测标准 Back / Side 候选；意图捕获后按你的实际布局保存。配置按设备分开保存，不能将另一台电脑的设备快照直接套用。

首次未发现可用的家庭影院空间音频时会提示；明确不可用的模式置灰。独占模式被禁用时，PCM 格式预检可能只能得到“无法确认”，此时仍允许选择，切换后进行验证，失败则尝试回滚。切换失败可在高级菜单查看日志。

Atmos / DTS:X 使用 Windows 空间音频服务要求的编码格式，不受标准 PCM 的 24 bit / 48 kHz 默认值约束。

五、高级菜单

鼠标停留在“高级”上片刻后展开，也可点击立即打开。主菜单左箭头表示子菜单通常从左侧展开；屏幕空间不足时调整位置。经过菜单间隙不会立即收起，移出高级区域后稍作等待再关闭。Esc 收起子菜单，再按 Esc 关闭主菜单。

【意图捕获】
先在 Windows 中设好所需音频模式、位深、采样率和扬声器大小，再点击“意图捕获”。程序识别当前属于哪一种模式，并更新该模式快照，同时进入手动锁定。
每个设备保存五种模式各一份；再次捕获同一种模式会替换原快照。无法识别的模式不会覆盖已有配置。需要备份时，先退出程序，再复制 profiles 文件夹。
PCM 恢复设备格式、混音格式、扬声器布局及全频标记。空间音频保存实际空间选择与扬声器配置；恢复由系统音频服务启用编码器，不直接重放编码载体格式字节。

【编辑规则 / 重新加载规则】
编辑 final-spatial-audio.ini，保存后点击“重新加载规则”。无需重启。

【查看日志】
打开 final-spatial-audio.log。日志约 1 MiB 时轮转为 .log.old。

【开机自启】
勾选后将当前程序路径登记为当前用户登录 Windows 时启动；取消勾选会移除该项。通常不需要管理员权限。自启后仍从手动锁定开始。
启用自启后请不要随意移动程序；需要移动时先取消自启，移动后重新勾选。卸载前也应先取消自启。

六、规则配置示例

分发包使用禁用的通用示例规则。若需要原神策略，可自行添加以下条目：

[Rule:YuanShen]
Enabled=1
Exe=YuanShen.exe
Scope=Running
Profile=7.1
Priority=300

字段说明：
Enabled：1 启用，0 禁用。
Exe：进程文件名，不是完整路径；不区分大小写。
Scope：Running 表示进程存在即匹配；Foreground 表示它拥有前台窗口。
Profile：Stereo、5.1、7.1、Atmos、DTS-X，也接受 Dolby Atmos、DTS:X。
Priority：数字越大越优先；同优先级按文件顺序决定。

高优先级后台程序可以维持高级模式，低优先级前台程序不会将其降级。没有规则匹配时使用 [Manager] 中的 Fallback，默认 Stereo。获胜规则指向不可用模式时不执行切换，也不擅自降级到其他规则。
DebounceMs 默认 500，可设为 100–5000。后台进程约每 2 秒检查，前台变化另有事件通知。最多 64 条规则。

七、设备变化与常见情况

• 约每 10 秒审计音频状态，外部修改不是瞬间检测；执行切换前还会复查状态。
• 约每 30 秒复查默认输出和模式能力。默认输出改变后转为手动锁定，并加载该设备配置。
• 模式置灰：检查 Windows 声音设置、HDMI/DisplayPort 连接、驱动和所需空间音频组件。
• 无声音或切换失败：先在 Windows 声音设置恢复可用模式，再查看日志。失败回滚是尽力恢复，不能保证驱动异常时一定成功。
• Windows 系统关闭透明效果或使用高对比度/读屏设置时，菜单可能使用实色或系统标准样式。
• 运行后没有新图标：程序是单实例，另一份 FSA 可能已运行；先退出旧副本。
• 配置文件损坏：程序保留原文件并停止该设备初始化。先退出并备份 profiles，再处理对应文件。

八、更新、移除与检查命令

更新：退出程序，备份规则和 profiles，然后用新版本替换 bin\FinalSpatialAudio.exe。请保留自己的配置。
移除：取消“开机自启”，退出程序，然后删除整个解压目录。不会自动重置系统当前声音模式。

可选检查命令（在发布目录运行）：
bin\FinalSpatialAudio.exe --check    初始化或校验本地配置，不切换音频
bin\FinalSpatialAudio.exe --smoke    启动托盘并读取状态，约两秒后退出
bin\FinalSpatialAudio.exe --stop     请求正在运行的 FSA 平滑退出

九、当前边界

这是原生用户会话托盘程序，不是 Windows 系统服务。当前没有图形规则编辑器或 AudioActive/WASAPI Session 规则。
部分音频策略及菜单材质使用非公开系统 ABI，已在开发机器验证，其他设备、Windows 更新或驱动组合仍可能存在兼容性差异。该便携构建未进行 Authenticode 数字签名。
